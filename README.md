# Zlonice teď

Veřejná jednostránková appka pro obec Zlonice (okres Kladno) — živě zobrazuje počasí,
kvalitu ovzduší, stav vody a pár místních zajímavostí z veřejných API.

Žádný framework, žádná databáze — čistý HTML + CSS + vanilla JS. Data se natahují
přímo v prohlížeči z veřejných API (Open-Meteo, ARES).

Živě na: https://davidsimunek91.github.io/zlonice-ted/

Nezávislý komunitní projekt, není oficiální stránkou Obecního úřadu Zlonice.
